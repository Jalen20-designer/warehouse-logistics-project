================================================================================
                        CORS HEADERS FLOW
================================================================================

Browser Request
    ↓
OPTIONS Preflight (automatic)
    ↓
api.php receives OPTIONS
    ├─ CORS headers sent (at very top)
    ├─ http_response_code(200)
    └─ exit
    ↓
Browser receives CORS headers
    ↓
Browser sends actual POST request
    ↓
api.php processes POST
    ├─ CORS headers sent again
    ├─ Parse JSON
    ├─ Route to appropriate handler
    └─ Return JSON response
    ↓
Browser receives response with CORS headers
    ↓
React processes response

================================================================================
                        TRAILING SLASH HANDLING
================================================================================

WITHOUT FIX:
  fetch('http://localhost/backend/auth')
    ↓
  Apache sees /auth (no trailing slash)
    ↓
  Redirects to /auth/ (301)
    ↓
  Browser resends request
    ↓
  CORS preflight fails on redirect
    ↓
  ERR_FAILED

WITH FIX:
  fetch('http://localhost/backend/auth/')
    ↓
  Apache sees /auth/ (with trailing slash)
    ↓
  Matches rewrite rule directly
    ↓
  Routes to api.php?route=auth
    ↓
  No redirect
    ↓
  CORS headers sent
    ↓
  Success ✅
