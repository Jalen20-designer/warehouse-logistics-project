================================================================================
                        HOW IT WORKS NOW
================================================================================

REGISTRATION:
  User fills form
    ↓
  Frontend sends POST to http://localhost/backend/auth/
    ├─ action: "register"
    ├─ username: "testuser"
    ├─ email: "test@example.com"
    └─ password: "TestPassword123!"
    ↓
  api.php
    ├─ CORS headers sent
    ├─ Parse JSON
    ├─ Set $_POST = $input
    └─ Include _auth/register.php
    ↓
  register.php
    ├─ Get data from $_POST
    ├─ Hash password with password_hash()
    ├─ Check if email exists
    ├─ Insert user with hashed password
    └─ Return success JSON
    ↓
  Frontend receives response
    └─ Redirects to login page

LOGIN:
  User fills form
    ↓
  Frontend sends POST to http://localhost/backend/auth/
    ├─ action: "login"
    ├─ email: "test@example.com"
    └─ password: "TestPassword123!"
    ↓
  api.php
    ├─ CORS headers sent
    ├─ Parse JSON
    ├─ Set $_POST = $input
    └─ Include _auth/login.php
    ↓
  login.php
    ├─ Get data from $_POST
    ├─ Query user by email
    ├─ Verify password with password_verify()
    └─ Return user data
    ↓
  Frontend receives response
    ├─ Stores user in localStorage
    └─ Redirects to /home

                        PASSWORD SECURITY
================================================================================

REGISTRATION:
  Input: "TestPassword123!"
    ↓
  password_hash("TestPassword123!", PASSWORD_DEFAULT)
    ↓
  Output: "$2y$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcg7b3XeKeUxWdeS86E36P4/KFm"
    ↓
  Stored in database (NOT plain text)

LOGIN:
  Input: "TestPassword123!"
    ↓
  Query database for user
    ↓
  Get hashed password: "$2y$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcg7b3XeKeUxWdeS86E36P4/KFm"
    ↓
  password_verify("TestPassword123!", "$2y$10$...")
    ↓
  Returns: true (password matches)
    ↓
  Login successful

                        QUICK TESTING

TEST 1: Register New User
  curl -X POST http://localhost/backend/auth/ \
    -H "Content-Type: application/json" \
    -d '{
      "action": "register",
      "username": "testuser",
      "email": "test@example.com",
      "password": "TestPassword123!"
    }'

  Expected: {"success": true, "message": "User registered successfully!"}

TEST 2: Login with Correct Password
  curl -X POST http://localhost/backend/auth/ \
    -H "Content-Type: application/json" \
    -d '{
      "action": "login",
      "email": "test@example.com",
      "password": "TestPassword123!"
    }'

  Expected: {"success": true, "user": {"id": 1, "username": "testuser", "email": "test@example.com"}}

TEST 3: Login with Wrong Password
  curl -X POST http://localhost/backend/auth/ \
    -H "Content-Type: application/json" \
    -d '{
      "action": "login",
      "email": "test@example.com",
      "password": "WrongPassword"
    }'

  Expected: {"success": false, "message": "Invalid email or password"}

TEST 4: Register with Duplicate Email
  curl -X POST http://localhost/backend/auth/ \
    -H "Content-Type: application/json" \
    -d '{
      "action": "register",
      "username": "anotheruser",
      "email": "test@example.com",
      "password": "AnotherPassword123!"
    }'

  Expected: {"success": false, "message": "Email already registered."}
